Smart Home Website Plan

Site Name

SmartHome Starter Guide

This name was chosen because it clearly reflects the purpose of the site: helping beginners get started with smart home technology in a simple and practical way.

Site Purpose

The website provides beginner-friendly information about smart home technology. It explains how smart devices work, introduces common devices, and gives practical advice on how to start building a smart home safely and affordably.

Scenarios

  • What smart home device should I buy first as a beginner?
  • How do I set up a smart home system without technical knowledge?

Color Scheme

  • Blue (#2E86AB): Used for headings and accents
  • Light Yellow (#F6F5AE): Used for page background
  • Orange (#F26419): Used for highlights and important elements

Typography

  • Segoe UI: Used for headings
  • Arial: Used for body text
